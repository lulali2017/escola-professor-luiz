# Escola Professor Luiz

Versão da Escola Professor Luiz preparada para publicação gratuita na internet.

## Estrutura

- `index.html`: aplicativo principal.
- `assets/`: imagens, animações e recursos visuais.
- `materiais_curso/`: PDFs utilizados nas aulas.
- `PUBLICACAO.txt`: informações da preparação.

O arquivo original offline permanece preservado fora desta pasta.
